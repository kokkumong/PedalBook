# PedalBook

실제 규격으로 페달보드를 배치하고, 뮬 매물 찾기와 구매 예산을 함께 계획하는 웹 편집기입니다.

현재 **Next.js·TypeScript·React Konva 배치 편집기, 핵심 모델명 자동 축약·뮬 전체 매물 검색, 수동 예산**까지 구현했습니다. 자동 시세 수집과 계정/서버 저장은 후속 단계입니다.

## 실행

Node.js 22.18 이상이 필요합니다. 의존성 버전은 lockfile에 고정하고 `npm install` 시 Git 훅도 설치합니다.

```sh
npm install
npm run dev
```

[http://127.0.0.1:3000](http://127.0.0.1:3000)에서 엽니다. 다른 포트는 `PORT=3001 npm run dev`로 지정합니다. 이전 SVG 프로토타입은 `npm run dev:prototype`으로 별도 실행할 수 있습니다.

- 보드 크기 프리셋·직접 입력·제조사별 모델 선택, 전체 페달 검색·제조사 필터
- 커스텀 페달 이름·크기·색상, 클릭/드래그 추가
- 이동·90도 회전·복제·삭제·undo/redo, zoom/pan/fit, 그리드·5mm 스냅·겹침/경계 경고
- 브라우저 자동 저장, 이전 보드 이관, JSON 내보내기/불러오기
- 페달별 뮬 검색어 복사·장터 이동·직접 입력 단가·보유 여부
- 전체 배치 또는 추가 구매 예산, 인스턴스별 합계와 가격 미상 개수

`R` 회전, `Delete` 삭제, 방향키 1mm 이동, `Shift` + 방향키 5mm 이동, `⌘/Ctrl+Z` 되돌리기, `⌘/Ctrl+Shift+Z` 다시 실행을 지원합니다. 목록에서 페달을 선택해 키보드로 조작할 수도 있습니다.

## 데이터와 저장 범위

규격은 제조사의 **가로 × 깊이**입니다. 제품 높이는 평면 배치의 세로가 아닙니다. 커넥터·케이블 공간은 별도로 확인하세요.

- [BOSS DS-1](https://www.boss.info/global/products/ds-1/specifications/), [CE-2W](https://www.boss.info/global/products/ce-2w/), [DD-8](https://www.boss.info/global/products/dd-8/), [TU-3](https://www.boss.info/global/products/tu-3/): 73 × 129mm
- [Strymon blueSky V2](https://www.strymon.net/product/bluesky/): 101.6 × 114.3mm

blueSky V2·BOSS를 포함한 카탈로그 페달은 PedalPlayground 사진을 우선 사용하고, 불러올 수 없으면 등록된 공식 제품 사진을 사용합니다. 커스텀 페달과 사진 오류는 자체 일러스트로 표시합니다. 이미지 출처·도입 상태는 [사진 및 검색 문서](docs/ASSETS_AND_SEARCH.md)에 기록합니다. 샘플 배치는 추천 신호 연결 순서가 아닙니다.

검수된 시장 가격은 아직 없으므로 **시세 정보 없음**을 표시합니다. 직접 입력한 금액은 시장 시세와 구분합니다. 미상 가격을 0원으로 확정하지 않고 누락 개수로 표시하며, 보유 페달은 추가 구매 합계에서 제외합니다. 선택 메뉴의 뮬에서 검색하기 버튼은 핵심 모델명을 20자 이내로 축약해 전체 이펙터 매물(판매완료 포함)을 엽니다. 단가와 보유 여부는 상단 예산 버튼으로 열고 페달 항목을 펼쳐 수정합니다.

저장은 이 브라우저·동일 주소의 localStorage를 사용합니다. 주소/포트가 바뀌면 저장 공간도 달라지므로 다른 기기로 옮길 때는 JSON을 내보내세요. 계정·클라우드 저장은 아직 없습니다.

현재 JSON은 `schemaVersion: 2`로, 좌표·규격은 mm, 가격은 원 단위입니다. v1 파일과 `pedalbook.prototype.v1` 저장본을 이관하되 원본 키는 보존합니다. 새 저장본은 `pedalbook.board.v2`에 revision과 함께 기록합니다. 손상·저장 용량 오류·다른 탭 변경 시 자동 저장을 멈추고 파일 백업을 안내합니다. Web Locks 지원 브라우저는 탭 간 쓰기를 직렬화하며, 미지원 환경은 저장 직전 비교로 충돌을 감지합니다. 동시 편집은 한 탭 사용을 권장합니다.

## 구조와 검증

`src/domain/`은 좌표·저장 형식·예산 계산, `src/hooks/`는 저장과 undo 상태, `src/components/`는 UI입니다. 캔버스는 클라이언트에서만 로드합니다.

```sh
npm run verify
npm run build
npm start
```

`verify`는 JavaScript 문법, Next.js 경로 생성·TypeScript 타입, 자동 테스트를 검사합니다. 좌표/회전·이관·JSON 검증·저장 충돌/실패·가격 신선도·예산 계산을 확인합니다. CI는 운영 빌드도 실행합니다. DB DDL과 수집 예제의 실제 외부 연동은 검사하지 않습니다.

## 전체 기어 라이브러리

현재 PedalPlayground 스냅샷의 **페달 8,891개·보드 268개**를 검색하고 제조사별로 선택할 수 있습니다. 페달은 클릭/드래그로 추가하고, 보드는 클릭하면 사진과 규격이 적용됩니다. 보드를 바꿔도 기존 페달 좌표는 유지하며 벗어난 항목을 경고합니다. 직접 규격을 적용하면 모델 사진 연결이 해제됩니다.

`npm run catalog:check`로 원본 업데이트를 확인하고 `npm run catalog:sync`로 가져온 뒤 verify/build 및 배포를 수행합니다. 자동 주기 실행은 아직 활성화하지 않았습니다. 사진은 PedalPlayground → 공식 등록 사진 → 대체 표시 순서로 요청하며, 추가 이미지 파일을 저장소에 일괄 복제하지 않습니다. 외부 이미지에 접근하려면 실행 서버의 인터넷 연결이 필요합니다. 자세한 동기화·출처·캐시·보드 형상 한계는 [사진/검색 문서](docs/ASSETS_AND_SEARCH.md)를 참고하세요.

### 3D 작업 화면

편집기 상단의 **3D로 보기**로 같은 배치를 입체로 편집합니다. 배경을 드래그하면 시점을 회전하고, 휠·두 손가락 제스처 또는 ± 버튼으로 확대/축소합니다. 페달을 직접 드래그하면 보드 평면 위에서 이동합니다. 전체 보기 버튼은 시점과 배율을 초기화합니다. 터치 시 두 손가락 확대는 배경에서 시작합니다.

2D/3D는 선택·mm 위치·90° 회전·5mm 스냅·경계/겹침 경고·되돌리기·자동 저장을 공유합니다. 페달 이동은 드래그를 놓을 때 한 번 기록하며 Esc, 포인터 취소 또는 창 포커스 해제는 이동을 취소합니다. 라이브러리 클릭과 보드로 드롭도 두 모드에서 지원합니다.

현재 3D 형상은 제품 사진을 윗면에 입힌 단순화된 입체입니다. BOSS 지원 5종(컴팩트 4종 59mm, GT-1000CORE 고무발 포함 65mm), ISO-10(32mm), blueSky V2(61mm)는 제조사 공식 높이를 사용하고, 나머지는 **높이 미상·임시 40mm**로 표시합니다. RockBoard 16종은 공식 도면 기반 구조를 사용하며, 다른 보드 두께는 16mm 예시입니다. 페달 노브·잭은 단순화합니다. 실제 케이스 수납이나 높이 간섭 판정 용도로 사용하지 않습니다. 높이와 출처는 3D 모드의 선택 패널에서 확인할 수 있습니다. WebGL을 사용할 수 없으면 안내와 2D 복귀 버튼을 제공합니다.

RockBoard 보드를 선택하면 경사진 천공 상판, 하부 보강대·열린 공간, MOD 구멍과 MAX의 2단 구조를 볼 수 있습니다. **하부 보기**로 뒤집고 **하부 공간 표시**로 제조사 공간도면의 구획을 확인하세요. 보드 정보에서 치수·공식 도면·파워 호환표·자료 간 차이를 확인할 수 있습니다. 예전 규격의 저장본은 **공식 규격 적용**을 눌러 상세 모델로 전환합니다. 장비를 선택하고 **보드 아래**를 누르면 하부로 내려가며 시점도 전환됩니다. 하부에서 드래그·회전하고 **상판**으로 복귀할 수 있습니다. **장비 높이**를 직접 입력할 수 있고 MOSKY ISO-10은 공식 32mm를 사용합니다. 도면 구획/높이 경고를 제공하며 실제 체결부·케이블의 정밀 충돌 판정은 별도 확인합니다. [재구성 근거와 한계](docs/ROCKBOARD_3D.md)


### 전체 창 작업 공간

작업 화면은 창 전체를 사용하며 라이브러리는 **＋ 기어 추가** 또는 `/`로 엽니다. 닫기/Esc로 숨겨도 검색 조건은 유지됩니다. 장비 상세와 예산은 필요할 때 옆으로 열립니다.

**상판 보기 / 하부 보기**는 2D와 3D에서 항상 사용할 수 있습니다. 2D 하부는 상판과 같은 X/Y 방향의 배치도이며 하부 장비만 선명하게 표시합니다. 3D는 아래 시점으로 전환하고 **보드 반투명**으로 보강대에 가려진 장비도 확인·이동할 수 있습니다. 하단 목록에서 하부 배지가 있는 장비를 선택하면 그 면으로 이동합니다. 구조가 없는 보드도 하부 배치를 미리 볼 수 있지만 실제 여유 공간은 확인되지 않은 상태로 안내합니다.

라이브러리의 **내 페달 만들기** 아래 **내 보드 만들기**에서 이름과 가로·세로(mm)를 입력하세요. 기존 장비 좌표·상하부·높이·예산은 그대로 유지하고 기존 제품 모델 연결을 해제합니다. 작은 보드로 바꿔 벗어난 장비는 경고하며 자동으로 이동하지 않습니다. 되돌리기로 이전 보드를 복원할 수 있습니다.


### BOSS 입체 외형과 하부 장착 방향

TU-3, DS-1, CE-2W, DD-8, GT-1000CORE는 공식 사양/사진을 참고해 케이스·노브·발판/풋스위치·잭을 입체로 표시합니다. 공식 전체 치수와 달리 개별 부품 형상은 사진 기반 근사입니다. 기존 저장 규격을 유지하며 상세 패널에서 공식 규격과 출처를 확인할 수 있습니다. [모델별 근거와 한계](docs/BOSS_3D.md)

하부로 옮기면 장비 바닥면이 보드 밑면에 붙고 조작면이 아래로 향하도록 뒤집힙니다. 평면 좌표와 회전 값은 유지되며 위로 되돌리면 원래 방향으로 복귀합니다.

## 패치 케이블

상단 **패치 케이블 → 케이블 추가**를 누르고 시작점과 끝점을 차례로 클릭하면 선이 연결됩니다. 양 끝점을 끌어 수정하며 5mm 스냅, 플러그 두께/길이·케이블 굵기 조절, 상판/하부 배치, 3D 미리보기, 저장·되돌리기를 지원합니다. 끝점은 보드 좌표에 고정되어 페달 이동과 독립적입니다. [사용법과 범위](docs/SIGNAL_CHAIN.md)

# 수동 패치 케이블

## 사용

상단 **패치 케이블 → 케이블 추가**를 누른 뒤 2D 캔버스에서 시작점과 끝점을 차례로 클릭한다. 두 점이 직선으로 연결된다. 놓은 원형 끝점을 끌어 수정하며 선도 바로 따라 움직인다. Esc 또는 취소로 미완성 배치를 버린다. 생성/이동/삭제는 각각 되돌리기·다시 실행할 수 있다.

현재 보는 면(상판/하부)에 케이블을 추가한다. 목록에서 선택하면 해당 면으로 이동하며, **2D에서 끝점 이동**으로 패널을 닫고 수정한다. 선택한 선은 Delete/Backspace 또는 목록의 ×로 지운다. 5mm 스냅은 시작/끝점 모두 적용되며 해제하면 자유 배치한다. 확대·이동은 저장 좌표에 영향을 주지 않는다.

끝점은 페달에 자동 부착하지 않는 보드 mm 좌표다. 페달을 이동하거나 회전해도 그대로 유지된다. 시그널 순서를 입력하거나 장비를 자동 연결하지 않는다. 장애물을 피해 우회하는 기능은 사용하지 않으며, 실제 잭 위치를 보고 직접 놓는다.

## 규격과 3D

**플러그·케이블 규격**에서 모든 선에 적용되는 외부 플러그 두께/길이와 케이블 굵기를 조정한다. 기본값 12/14/4mm는 특정 제조사 검증값이 아닌 편집 가능한 예시다. 플러그는 선택한 양 끝점에서 연결 방향 안쪽으로 놓인다. 2D에서는 직사각 하우징과 원형 이동 손잡이, 3D에서는 원통으로 표시한다. 두 플러그 길이보다 점 사이가 가까우면 겹침 가능성을 알린다.

3D에서도 같은 양 끝점을 직선으로 연결한다. 끝점 좌표·높이에서 각각의 높이를 mm로 지정할 수 있으며 기본 12mm다. 상판은 표면 위, 하부는 상판 밑면에서 아래 방향의 거리다. 편집은 2D에서 한다. 장비 간섭, 보드 관통, 실제 L자 플러그 형상이나 최소 굽힘 반경을 검증한 모델은 아니다.

표시 길이는 두 점 사이 **평면 직선거리**이며 높이/굽힘/작업 여유를 포함하지 않아 실제 구매 길이와 다르다.

## 저장 및 호환

v2 보드에 선택적인 `cableLayout`을 저장한다. 각 선은 고유 ID, `start`/`end`의 x/y/높이(mm), 상판/하부, 색상을 가진다. 공통 규격과 표시 여부도 저장한다. 최대 100개, x/y 범위 ±5000mm, 높이 0–500mm, 두 점 사이 최소 1mm를 검증한다. 중복 ID·비정상 숫자·범위 밖 값은 가져오기에서 거부한다.

기존 v1/v2 보드는 그대로 불러온다. 이전 자동 연결의 `signalChain`은 호환성을 위해 보존하지만 화면에는 그리지 않으며 수동 케이블로 임의 변환하지 않는다. 수동 끝점은 기존 브라우저 저장·JSON 내보내기/가져오기·이력을 사용한다.

## 검증

`tests/manual-cables.test.ts`: 저장 왕복/옛 보드 호환/잘못된 데이터, 불변 편집과 끝점 독립성, 개수 제한, 확대·이동과 스냅, 3D 양 끝점·높이·하부·표시 여부를 확인한다. `tests/signal-chain.test.ts`는 레거시 데이터/계산 호환과 자동 선 미표시를 확인한다. 실제 제품 측정/배선 시공 검증은 포함하지 않는다.

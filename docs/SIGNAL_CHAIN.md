# 시그널 체인과 패치 케이블

## 사용

상단 **시그널 체인**을 열고 소리가 흐르는 순서대로 배치된 페달을 추가한다. 각 행의 ↑/↓로 순서를 변경하거나 ×로 체인에서 제외한다. 파워서플라이는 오디오 체인에 추가하지 않는다. 현재 범위는 하나의 모노 직렬 체인이며 스테레오·분기·스위처 루프·외부 기타/앰프 연결은 포함하지 않는다.

각 페달의 **잭 위치 조정**에서 IN/OUT의 좌우/상하 방향과 위치 비율을 바꿀 수 있다. 위치는 회전 전 정면 기준이며 좌우 잭은 위부터, 상하 잭은 왼쪽부터의 비율이다. 초기 IN=오른쪽 30%, OUT=왼쪽 30%, 높이=장비 높이의 45%는 제조사 검증값이 아닌 편집 가능한 가정이다. 3D 잭 높이는 별도로 mm 입력할 수 있다. 실제 제품의 잭 위치에 맞춰 조정해야 한다.

**플러그·케이블 규격**은 체인 전체에 적용한다. 플러그 두께는 잭 안의 금속 팁이 아닌 외부 하우징의 최대 폭/두께이며 기본 12mm, 돌출은 14mm, 케이블 직경은 4mm다. 모두 제품 특정값이 아닌 예시다. 각 플러그를 보수적인 직사각 점유 공간으로 계산하고 3D에서는 같은 길이·직경의 원통으로 보여준다. 특정 L자 플러그의 CAD 형상이나 체결 인증이 아니다.

## 경로

- 인접한 순서의 OUT → IN을 연결한다. 회전과 하부 반전을 적용한 잭 좌표를 사용한다.
- 같은 면에 있는 모든 장비(체인 밖 장비 포함)와 연결된 플러그를 장애물로 사용한다. 케이블 반지름 + 3mm의 평면 여유를 확보한다.
- 장애물 경계를 지나는 직교 격자에서 A* 경로를 찾는다. 길이 외에 꺾임·기존 선과의 겹침/교차에 비용을 주어 정리한다. 체인 순서대로 계산하는 휴리스틱이므로 전역 최적·교차 없음·실제 시공 가능성을 보장하지 않는다.
- 플러그 충돌, 높이 초과, 공간 부족은 각 연결 아래에 표시한다. 유효 경로가 없는 연결은 빨간 점선으로 의도만 표시하고 길이를 제공하지 않는다.
- 2D와 3D는 같은 경로를 사용한다. 3D는 잭 끝에서 보드 표면으로 내려가는 구간을 더한 미리보기다. 보드 슬롯/보강대/단차의 입체 충돌과 케이블의 최소 굽힘 반경은 아직 검증하지 않는다. 상하판 사이의 관통 연결은 자동 경로 대신 확인 경고를 표시한다.
- 페달을 놓거나 회전하면 재계산한다. 드래그 중에는 이전 위치에 붙은 선이 남지 않도록 숨기고, 놓은 뒤 다시 표시한다.
- 표시 길이는 플러그 외부 끝 사이의 **평면 경로** 길이다. 높이·굽힘·커넥터 내부·작업 여유가 포함되지 않아 구매 길이로 사용하지 않는다.

## 저장 및 호환

v2 보드에 선택적인 `signalChain`을 추가했다. `nodes`는 인스턴스 ID와 입출력 잭 설정을 저장하며 플러그 두께/돌출, 케이블 직경, 표시 여부를 저장한다. 좌표와 길이는 mm다. 경로는 저장하지 않고 배치에서 다시 생성한다. 기존 v1/v2 보드에는 체인을 임의 생성하지 않는다.

중복/존재하지 않는 인스턴스, 잘못된 방향/범위/숫자는 가져오기에서 거부한다. 페달 삭제 시 체인에서도 제거하고 전후 페달을 연결한다. 복제한 페달은 자동으로 체인에 추가하지 않는다. 기존 브라우저 저장·파일 내보내기·되돌리기/다시 실행 이력을 사용한다.

## 검증

`tests/signal-chain.test.ts`에서 저장 왕복/옛 보드 호환, 잘못된 참조, 순서와 삭제 후 재연결, 회전/하부 잭 변환, 장애물 우회/막힌 경로, 플러그 크기에 따른 연결 가능 여부, 이동 후 재계산, 같은 장비 잭 사이 충돌, 상하판 연결 경고, 3D 메시와 표시 토글을 검증한다. 실제 제품 측정이나 배선 시공 검증을 의미하지 않는다.

# 사진 자산과 뮬 검색 연결

## 이미지 적용 방식

`src/domain/photos.ts`가 페달 ID와 검수한 사진·출처를 연결한다. 사진 경로는 보드 JSON에 저장하지 않아 기존 v1/v2 보드에도 즉시 적용되며, 가져온 JSON의 임의 원격 이미지 URL을 로드하지 않는다. PNG 원본을 `public/images/pedals/`에서 같은 origin으로 제공해 외부 핫링크와 CORS에 의존하지 않는다.

라이브러리와 선택 패널은 `object-fit: contain`, Konva 캔버스는 `containImage`로 원본 종횡비를 유지한다. 저장된 mm 규격·중심 좌표·회전·충돌 영역은 변하지 않는다. 사진의 투명 여백/잭 때문에 보이는 외곽과 규격 영역에 소폭 차이가 있을 수 있다. 사진은 식별용이며 케이블 공간은 별도 확인한다. 사진 오류 시 기존 SVG 일러스트로 돌아간다.

- 1000 × 1100 PNG, 파일 편집/배경 제거/생성형 재작성 없음
- SHA-256: `cc44f09909a487d9dfc430423996dfb7a7d31811a90729d9fd4d2cd00b5b1081`

PedalPlayground의 공개 GitHub 저장소는 확인 시점에 루트 LICENSE와 GitHub license 정보가 없어 이미지 일괄 복제를 하지 않았다. BOSS의 공식 제품 이미지 자료실은 다운로드에 약관 동의를 요구하며 프로젝트의 웹 서비스 재배포 허용을 확인하지 못했다. 공개된 DS-1 CC 사진도 확인했지만 비스듬한 구도·케이블·배경으로 인해 배치용 정면 사진에 적합하지 않아 도입하지 않았다.

BOSS 사진은 직접 촬영한 정면 사진, 명시적으로 허락받은 제품 사진, 적합한 공개 라이선스 사진을 확보한 뒤 같은 manifest에 추가한다. 모델/세대, 정면 구도, 원본 비율, 투명 배경, 출처·권리 조건을 확인하고 UI와 원본 해시 테스트를 갱신한다. 확보 전까지 실제 사진이라고 표시하지 않는다.

## 뮬 검색 확인

2026-10-31 일반 브라우저에서 공개 장터 검색 UI를 사용해 DS-1 검색과 이펙터·판매중 필터를 직접 실행했다. HTTP 수집 도구의 403과 달리 브라우저의 공개 페이지는 정상 열렸다. 별도 로그인·차단 우회·자동 수집 없이 링크 이동 흐름만 검증했다.

| 파라미터 | 값 | 의미 |
|---|---|---|
| `qf` | `title` | 제목 |
| `qs` | 사용자 검색어 | 기본은 모델명, 변경 가능 |
| `ct1` | `이펙터` | 악기 카테고리 |
| `sell_status` | `판매중` 또는 빈 문자열 | 판매중 또는 전체 |
| `of`, `od` | `wdate`, `desc` | 최신순 |
| `andor` | `and` | 입력 단어 모두 포함 |
| `page`, `map`, `mode`, `v` | `1`, `list`, `list`, `l` | 첫 페이지 목록 |

`muleSearchUrl`은 고정된 HTTPS 장터 주소에 URLSearchParams로 값만 인코딩한다. 빈 검색어·120자 초과 입력은 링크를 만들지 않는다. 기본 검색어를 모델명으로 지정해 영문 BOSS를 넣지 않은 한글 제목도 찾을 수 있게 하되 blueSky V2 등 세대 표기는 유지한다. 이 검색은 모델 매칭을 보장하지 않으며 모디·구형·한정판·묶음 매물이 섞일 수 있음을 안내한다. 장터 첫 화면과 검색어 복사도 제공한다.

실제 매물 목록/가격을 앱으로 수집하거나 시장 통계를 생성하지 않는다. 뮬 화면 하단은 동의 없는 자동 수집을 허용하지 않는다고 명시하므로, 시세 수집은 접근 허용과 별도 데이터 설계를 확인한 후 진행한다.

## 전체 카탈로그 확장 (2026-11-02)

사용자가 요청한 비상업용 프로토타입의 외부 카탈로그 참조 범위로 확장했다. 현재 스냅샷은 페달 8,891개, 보드 268개이며 원본 커밋·동기화 시각을 `src/catalog-snapshot.json`에 보관한다. 목록에는 원본의 색상/에디션 차이 및 라이저 등도 포함된다. 원본은 효과 분류를 제공하지 않아 추가 페달은 `미분류`로 표시한다. 기존 5개는 원본 사진 파일명과 명시적으로 연결하여 중복 추가하지 않고 기존 ID·제조사 규격을 유지한다. 나머지 인치 규격은 25.4배하여 mm로 변환한다.

### 사진 우선순위와 범위

1. `PEDAL_PHOTOS`에 등록한 공식 사진을 우선 사용한다. 기존 blueSky와 BOSS DS-1, CE-2W, DD-8, TU-3 제품 페이지의 정면 사진을 연결했다. BOSS 사진은 흰 배경 원본을 유지한다.
2. 공식 매핑이 없거나 서버에서 공식 사진 로딩이 실패하면 같은 모델의 PedalPlayground 원본 사진을 사용한다. 수천 개 모델의 모든 제조사 사이트를 이미 조사했다는 의미는 아니다. 공식 사진을 검수하는 대로 manifest에 추가한다.
3. 사진이 없거나 네트워크 오류라면 페달은 일러스트, 보드는 규격 바탕과 사진 사용 불가 안내로 표시한다.

공식 BOSS 사진: DS-1 `ds1_gal.jpg`, CE-2W `CE-2W_F_gal.jpg`, DD-8 `dd-8_top_gal.jpg`, TU-3 `tu-3_top_gal.jpg` (각 `https://static.roland.com/assets/images/products/gallery/`). 사진의 원본 출처는 선택 패널에서 확인할 수 있다. 공식 사진 연결이 실패하면 실제 표시는 PedalPlayground 대안일 수 있다.

위의 초기 BOSS 사진 미완료 상태는 이 확장으로 대체된다. 공개 사진이나 비상업용 목적이 포괄적인 재배포 라이선스를 뜻하지 않으며 원저작자의 권리는 유지된다. 추가 사진 원본은 Git에 일괄 복제하지 않고 사용자가 보는 항목만 외부에서 가져와 실행 환경의 무시된 캐시에 저장한다. 공개 서비스 배포/재배포의 권리 검토가 완료되었다고 표현하지 않는다.

### 동기화

```sh
npm run catalog:check     # 최신 원본과 비교, 파일 변경 없음
npm run catalog:sync      # 검증 후 스냅샷 원자적 교체
npm run verify
npm run build
```

`beta` 커밋을 한 번 확정하고 동일 커밋의 `public/data/pedals.json`, `pedalboards.json` 두 파일만 받는다. 페이지 단위 크롤링이나 이미지 대량 요청은 하지 않는다. HTTP 실패·타임아웃·잘못된 규격/경로·중복 ID가 발생하면 기존 스냅샷을 유지한다. 삭제된 ID가 있으면 자동 교체하지 않으며, 변경 내역을 검토한 뒤 `npm run catalog:sync -- --allow-removals`로 명시적으로 반영한다. 모델명/이미지 파일명 변경은 삭제+추가로 취급한다. 기존 저장 보드에는 모델 정보와 규격이 포함되어 삭제 이후에도 배치를 유지하며 사진은 대체될 수 있다.

이번에는 수동 재실행 명령을 제공하며 자동 스케줄은 활성화하지 않았다. 업데이트를 적용하면 빌드/배포도 다시 수행해야 한다. 마지막 정상 스냅샷은 원본 서버 장애 중에도 검색·배치에 사용할 수 있다. 원본 `Tech 21 NYC / Boost RVB Trails`는 이미지 확장자가 누락되어 있지만 목록에서 제외하지 않는다.

### 이미지 요청·캐시

`/api/catalog-image/[kind]/[id]`는 스냅샷에 있는 ID만 허용하며 임의 URL을 받지 않는다. 공식/고정 커밋의 이미지 출처만 서버에서 요청하고 리다이렉트는 따르지 않는다. 요청 제한 15초·8MB, 디코딩 제한 2,500만 픽셀, 동시 다운로드 최대 6개, 동일 요청 중복 제거를 적용한다. 최대 700px WebP로 변환하되 확대하거나 배경을 변경하지 않는다. 원본 URL+변환 버전을 해시한 `.cache/catalog-images` 디스크 캐시를 사용하고 브라우저는 하루 캐시한다. 실패는 60초간 재요청을 줄이고 UI는 대체 이미지를 제공한다. 캐시 경로가 쓰기 불가해도 다운로드 결과는 제공하지만 다음 요청에서 다시 가져올 수 있다. 운영 저장 공간에 맞춰 오래된 `.cache/catalog-images` 파일을 정리할 수 있다.

### 보드 모델과 저장 호환

라이브러리의 보드 탭에서 제조사·모델명으로 검색해 보드를 선택한다. 선택하면 사진과 mm 규격을 적용하되 기존 페달 위치·회전·가격·보유 여부는 변경하지 않는다. 작은 보드로 바뀌어 벗어난 페달은 기존 경계 경고로 표시한다. 되돌리기로 이전 보드를 복원할 수 있다.

v2 저장 형식에 선택적 `modelId`를 추가했다. 기존 v1/v2 보드는 그대로 열리고, 모델 ID를 모르는 경우에도 저장된 규격·페달 배치를 유지한다. 직접 규격을 변경하면 모델 연결을 해제해 제품 사진을 임의로 늘리지 않는다. 저장된 규격이 현재 카탈로그 모델과 다를 때에도 기본 보드로 표시한다.

사진은 제조사별 레일/외형을 보여주지만 충돌/경계 검사는 전체 사각 규격을 기준으로 한다. 구멍, 빈 레일, 경사면, 실사용 면적, 잭·케이블 간격 및 라이저의 높이는 정밀하게 검사하지 않는다. 최대 한 개 보드를 바탕으로 선택하며 다중 보드·라이저 중첩은 후속 범위다.

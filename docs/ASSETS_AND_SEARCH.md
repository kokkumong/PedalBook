# 사진 자산과 뮬 검색 연결

## 이미지 적용 방식

`src/domain/photos.ts`가 페달 ID와 검수한 사진·출처를 연결한다. 사진 경로는 보드 JSON에 저장하지 않아 기존 v1/v2 보드에도 즉시 적용되며, 가져온 JSON의 임의 원격 이미지 URL을 로드하지 않는다. PNG 원본을 `public/images/pedals/`에서 같은 origin으로 제공해 외부 핫링크와 CORS에 의존하지 않는다.

라이브러리와 선택 패널은 `object-fit: contain`, Konva 캔버스는 `containImage`로 원본 종횡비를 유지한다. 저장된 mm 규격·중심 좌표·회전·충돌 영역은 변하지 않는다. 사진의 투명 여백/잭 때문에 보이는 외곽과 규격 영역에 소폭 차이가 있을 수 있다. 사진은 식별용이며 케이블 공간은 별도 확인한다. 사진 오류 시 기존 SVG 일러스트로 돌아간다.

## 적용 자산 및 출처

| 모델 | 상태 | 출처/사용 범위 |
|---|---|---|
| Strymon blueSky V2 | 실제 정면 투명 PNG 적용 | [Strymon Press](https://www.strymon.net/press/)의 blueSky V2 제품 보도용 이미지. 제품 식별·소개에 사용하며 저작권은 Strymon에 있음. 오픈소스 라이선스로 재허가하지 않음 |
| BOSS DS-1, CE-2W, DD-8, TU-3 | 자체 일러스트 유지 | 웹 서비스에 도입할 수 있는 정면 사진의 재사용 조건 추가 확인 필요 |

blueSky 원본: https://www.strymon.net/wp-content/uploads/2022/08/blueSky_Homepage.png

- 확인일: 2026-10-31
- 1000 × 1100 PNG, 파일 편집/배경 제거/생성형 재작성 없음
- SHA-256: `cc44f09909a487d9dfc430423996dfb7a7d31811a90729d9fd4d2cd00b5b1081`
- UI에서 사진 출처 링크 제공. 일반 소프트웨어 라이선스가 이 파일의 권리를 대체하지 않는다.

PedalPlayground의 공개 GitHub 저장소는 확인 시점에 루트 LICENSE와 GitHub license 정보가 없어 이미지 일괄 복제를 하지 않았다. BOSS의 공식 제품 이미지 자료실은 다운로드에 약관 동의를 요구하며 프로젝트의 웹 서비스 재배포 허용을 확인하지 못했다. 공개된 DS-1 CC 사진도 확인했지만 비스듬한 구도·케이블·배경으로 인해 배치용 정면 사진에 적합하지 않아 도입하지 않았다.

BOSS 사진은 직접 촬영한 정면 사진, 명시적으로 허락받은 제품 사진, 적합한 공개 라이선스 사진을 확보한 뒤 같은 manifest에 추가한다. 모델/세대, 정면 구도, 원본 비율, 투명 배경, 출처·권리 조건을 확인하고 UI와 원본 해시 테스트를 갱신한다. 확보 전까지 실제 사진이라고 표시하지 않는다.

## 뮬 검색 확인

2026-10-31 일반 브라우저에서 공개 장터 검색 UI를 사용해 DS-1 검색과 이펙터·판매중 필터를 직접 실행했다. HTTP 수집 도구의 403과 달리 브라우저의 공개 페이지는 정상 열렸다. 별도 로그인·차단 우회·자동 수집 없이 링크 이동 흐름만 검증했다.

| 파라미터 | 값 | 의미 |
|---|---|---|
| `qf` | `title` | 제목 |
| `qs` | 사용자 검색어 | 기본은 모델명, 변경 가능 |
| `ct1` | `이펙터` | 악기 카테고리 |
| `sell_status` | `판매중` 또는 빈 문자열 | 판매중 또는 전체 |
| `of`, `od` | `wdate`, `desc` | 최신순 |
| `andor` | `and` | 입력 단어 모두 포함 |
| `page`, `map`, `mode`, `v` | `1`, `list`, `list`, `l` | 첫 페이지 목록 |

`muleSearchUrl`은 고정된 HTTPS 장터 주소에 URLSearchParams로 값만 인코딩한다. 빈 검색어·120자 초과 입력은 링크를 만들지 않는다. 기본 검색어를 모델명으로 지정해 영문 BOSS를 넣지 않은 한글 제목도 찾을 수 있게 하되 blueSky V2 등 세대 표기는 유지한다. 이 검색은 모델 매칭을 보장하지 않으며 모디·구형·한정판·묶음 매물이 섞일 수 있음을 안내한다. 장터 첫 화면과 검색어 복사도 제공한다.

실제 매물 목록/가격을 앱으로 수집하거나 시장 통계를 생성하지 않는다. 뮬 화면 하단은 동의 없는 자동 수집을 허용하지 않는다고 명시하므로, 시세 수집은 접근 허용과 별도 데이터 설계를 확인한 후 진행한다.

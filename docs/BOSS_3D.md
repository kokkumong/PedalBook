# BOSS 3D 외형 재구성

공식 제품 페이지의 전체 치수와 사진을 참고해 직접 작성한 절차적 메시다. 제조사 CAD/실측 메시가 아니며, 내부 구조나 케이블·체결 공차를 검증하지 않는다. 조사일 2026-11-04, 반영일 2026-11-05.

GT-1000CORE는 고무발 포함 높이 65mm를 기본으로 쓴다. 공식 고무발 제외 높이는 63mm이며 사용자가 높이 입력으로 바꿀 수 있다.

부품 크기·곡률·노브 간격·하우징 단차·단자 위치는 공식 사진에서 비율을 참고한 근사다. 잭은 단순화하며 실제 플러그 돌출/체결 형상을 나타내지 않는다. 튜너와 GT의 화면/LED는 시각화용 정적 표시다. 텍스트는 코드로 생성하며 공식 사진 파일을 추가 복제하지 않는다.

전체 메시를 공식 외곽 치수로 정규화한 뒤 저장된 가로/세로와 인스턴스 높이에 맞춘다. 따라서 기존 GT-1000CORE의 PedalPlayground 규격 172.974 × 136.652mm를 불러올 때도 장비 크기/좌표를 자동 변경하지 않는다. 패널은 공식 규격과 저장 규격에 맞춰 표시한다는 사실을 안내한다. 2D 사진과 규격은 기존 그대로다.

하부 장착은 로컬 X축으로 180도 뒤집어 바닥면을 보드 밑면에 붙인다. 조작면이 아래로 향하며 2mm 부착 여유를 둔다. 저장 X/Y와 평면 회전 값은 유지한다. 2D 하부는 상판 좌표 기준 배치도이므로 뒤집힌 3D 카메라 화면과 방향이 같다는 뜻은 아니다.

검증: 공식 외곽 범위, 모델별 노브/풋스위치 수, 조작부 raycast, 상하부 면의 법선 방향, 모든 90도 회전과 RockBoard 경사/MAX 단차에서 좌표 변환 및 하부 여유 계산을 테스트한다.

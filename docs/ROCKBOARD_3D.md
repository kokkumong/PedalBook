## 자료 간 차이와 해석

- 제품 페이지의 10° 경사/전체 높이 표기와 도면의 mm 치수가 일치하지 않는다. 일부 제품 페이지는 TRES·QUAD·CINQUE에 동일한 높이 37–71mm를 표기한다. 렌더링은 하부 공간도면의 앞뒤 높이 차와 길이를 우선하며, 경사를 atan((뒤 높이 − 앞 높이 − 단차) / 하부 길이)로 유도한다. 전체 높이를 별도 확정 사양으로 제시하지 않는다.
- Tres 3.2 제품 사양 가로는 598mm지만 연결된 설계 도면은 622mm다. 외곽에는 제품 사양 598mm, 하부에는 해당 모델의 공간도면을 적용한다. 실제 제품 세대는 확인이 필요하다.
- Duo 2.2는 V2 공간도면의 180 / 80 / 180mm 구획을 채택한다. 이전 설계 도면의 보강대 간격과 다르다.
- Cinque 5.3 MAX는 826 × 498mm, 뒤쪽 상단 길이 218mm, 공간도면 F의 46mm 단차를 사용한다. E의 175mm를 상단 하부 공간 길이로 표시하고, 나머지는 낮은 공간으로 보수적으로 나눈다. 천공 배열은 상단 4열·하단 6열이다.

## 확정 치수와 단순화 범위

- 기본 상판 슬롯 깊이 18mm, 열 피치 47mm, 대표 슬롯 길이 60mm·가로 간격 16mm, 번갈아 배열한다. 끝 슬롯 길이는 외곽 너비로 유도한다. 모델별 끝 여백·라운드·비정형 슬롯을 완전 복제하지는 않는다.
- 보강대 너비는 52mm, 수는 하부 구획 수 − 1이다. 구획의 절대 위치가 모두 치수화되지 않아 남는 끝 여백을 좌우 균등 배분한다. 보강대의 작은 케이블/체결 슬롯은 단순화했다.
- MOD 개구부는 163 × 40.5mm다. 도면상 위치를 반영하되 일부 중심 위치/모서리 반경은 근사한다. MAX는 뒤쪽 2 × 2개와 측면 개구부가 있다. MOD 모듈은 설치하지 않은 상태다.
- 판 두께 2.5mm, 고무발 높이 11mm·반경 8–10mm, 측면 케이블 구멍 반경 9mm, 하부 끝 플랜지 너비 18mm는 도면 치수 미제공 부분의 시각화용 추정치다. 도면의 공식 여유 공간과 구분한다.
- 세대 차이, 조립 공차, 나사·브래킷·벨크로·파워 트레이, 커넥터/케이블 돌출, 설치된 MOD 점유 공간은 반영하지 않는다. 파워 배치와 입체 간섭 판정은 후속 기능이다. 현재는 파워 형상을 하부로 드래그해 장착하는 기능이 없다.

## 저장 및 조작

- 새로 선택하는 RockBoard 16종은 공식 외곽 mm를 사용한다. 다른 브랜드와 원본 카탈로그 스냅샷은 그대로 유지한다.
- 기존 저장본은 치수·좌표를 자동 변경하지 않는다. modelId는 있으나 이전 치수일 때 ‘공식 규격 적용’으로만 상세 3D를 활성화한다. 적용은 undo/redo 가능하며 기존 페달 좌표를 유지한다. 작아진 외곽의 경계 경고를 확인한다.
- 저장 schemaVersion 2는 동일하다. 저장 X/Y와 렌더링 X/Z는 평면도상의 같은 mm 좌표다. 경사가 있어도 외곽 가로·세로를 축소하지 않고, 높이만 tan(경사)로 계산한다. 드래그의 월드 X/Z 변화가 저장 X/Y 이동량이다. 회전한 페달도 같은 상판 경사를 따른다.
- MAX 단차에 걸친 페달은 높은 면에서 표시하고 이동 경고를 제공한다. 저장 위치를 자동 이동하지 않는다.
- ‘상판 보기’·‘하부 보기’·‘하부 공간 표시’는 카메라/표시만 바꾸며 저장본을 수정하지 않는다. 하부 시점에서는 구조를 회전해서 볼 수 있고 페달 이동은 상판 시점에서 한다.

## 검증 범위

자동 테스트는 16종 매핑, 이전 저장본 보존, 경사 좌표 왕복/드래그, MAX 단차, 실제 관통 슬롯·열린 하부, 형상 경계·유한 좌표·공간 구획 너비를 검증한다. 제조사의 실물 치수·파워 장착 결과를 보증하는 검사는 아니다.

`npm run verify`의 52개 테스트와 `npm run build`를 통과했다. Chrome 데스크톱에서는 Quad 4.1의 경사면 드래그/스냅/undo/redo, 하부 회전·공간 표시·줌, 2D 전환·저장 복원, MAX 상·하부, Duo 하부, Tres 치수 차이 표시를 확인했다. 이전 저장본의 명시적 적용/undo와 390px 화면의 하부 제어·가로 넘침 없음도 확인했다. 모바일 실기기 및 실제 파워 장착은 검증하지 않았다.
